# NeoForge 26.1.2.78 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port Camera Inertia to Minecraft 26.1.2 with NeoForge 26.1.2.78.

**Architecture:** Keep the mod in place and migrate the build and API surface around the existing client-side camera controllers. Use compiler feedback as the regression test for the port.

**Tech Stack:** Java 25, Gradle 9.2.1, NeoForge ModDevGradle 2.0.141, Minecraft 26.1.2, NeoForge 26.1.2.78.

## Global Constraints

- Preserve `mod_id=camera_inertia`.
- Preserve current gameplay behavior unless the target API requires a compatibility adjustment.
- Do not introduce new runtime dependencies.
- Verify with `./gradlew.bat build`.
